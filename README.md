# Power Query Sales Data Transformation & Analysis

## Project Overview

This project demonstrates a complete data preparation and analysis workflow using Microsoft Excel and Power Query.

The project starts with raw sales data and applies data cleaning, transformation, merging, and analysis steps to produce structured and reusable datasets.

## Tools & Technologies

* Microsoft Excel
* Power Query
* Power Query M
* Web Data / Currency Data

## Data Preparation Process

The main Power Query workflow includes:

* Importing raw data
* Data cleaning and transformation
* Handling missing and inconsistent values
* Changing data types
* Splitting and transforming columns
* Merging queries
* Expanding merged data
* Creating calculated columns
* Combining sales data with currency information
* Preparing datasets for analysis

## Project Outputs

The final workbook contains four main output queries:

### 1. Sales Final

The main cleaned and transformed sales dataset.

### 2. Branch Analyze

A dataset prepared for analyzing sales performance by branch.

### 3. Sales Analyze

A dataset prepared for sales analysis and reporting.

### 4. Web Currency

Currency and market data retrieved from the web and prepared for use in the project.

## Refreshable Data Pipeline

The Power Query transformations are designed as a reusable data pipeline.

When the source data or web-based currency data changes, the queries can be refreshed in Excel to update the output datasets.
